# Transformers Movie Review Sentiment Analysis

A Transformer-based sentiment analysis project using PyTorch and the IMDB movie review dataset.

## Project Overview

This project builds and trains a Transformer model to classify movie reviews as either positive or negative.

The project was completed as part of the Udacity AWS AI Programmer program.

## Objectives

- Load and prepare the IMDB movie review dataset.
- Build a Transformer-based model using PyTorch.
- Train the model for binary sentiment classification.
- Evaluate the model's performance on movie reviews.
- Use the trained model to predict whether reviews express positive or negative sentiment.

## Technologies Used

- Python
- PyTorch
- Transformers
- Jupyter Notebook
- IMDB Dataset
